# 黑马头条后台管理系统 · 测试实战

对黑马头条后台管理网页系统开展的一轮完整功能 + 接口测试，从需求分析到测试报告全流程。

## 测试对象

黑马头条后台管理系统（SpringBoot 微服务 + MySQL，Edge 浏览器），覆盖 5 个核心模块：

- 用户审核
- 频道管理
- 内容审核
- 内容管理
- 敏感词设置

## 测试环境

- OS：Windows 11
- 浏览器：Microsoft Edge
- 后端：SpringBoot 微服务
- 数据库：MySQL

## 交付物

| 文件 | 说明 |
|---|---|
| `测试计划.docx` | 测试目标、范围、环境、进度、风险 |
| `用户审核与频道管理测试用例.xlsx` | 按模块编写的测试用例（含前置条件、步骤、预期结果） |

## 执行结果

- 用例总数：**26 条**（P0 核心 18 条 / P1 非核心 8 条），全部执行
- 发现缺陷：**4 个**
  - 严重 1：频道禁用状态未同步至自媒体端（业务逻辑 bug，阻断上线）
  - 一般 2：表单长度校验缺失
  - 次要 1：特殊字符搜索导致页面崩溃
- 结论：存在 1 个严重缺陷，当前版本**不允许上线**，需修复并回归通过后再发版

## 流程

需求分析（1 天）→ 编写用例（1 天）→ 执行测试 / 提交缺陷（2 天）→ 回归验证 + 测试报告（3 天）
